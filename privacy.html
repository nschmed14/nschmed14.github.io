V.i.C.T.O.R. Privacy Policy

Last updated: October 2026

About this application

V.i.C.T.O.R. is a personal assistant application built and used solely by its owner. It is not offered to the public, and no one other than the owner uses it.

Data accessed

With the owner's explicit authorization, V.i.C.T.O.R. accesses the owner's own Google Calendar events and Gmail messages. This data is used only to provide assistant features to the owner, such as viewing and scheduling events, summarizing email, and drafting or sending messages at the owner's direction.

Storage and sharing

Data is processed and stored on the owner's own computer. It is not sold, shared with, or transferred to any third party, and it is not used for advertising or to train AI models.

Google API Services

V.i.C.T.O.R.'s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions).

Contact

Questions can be directed to the owner via GitHub: github.com/nschmed14
